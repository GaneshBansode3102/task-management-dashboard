# Kanban Task Management Dashboard

A responsive task management app with drag-and-drop functionality using React, Material-UI, and react-dnd.

## 🧰 Technologies Used

- React
- Material-UI
- react-dnd
- json-server (mock API)

## 📦 Features

- View tasks in a Kanban-style 3-column board
- Add new tasks (modal form)
- Drag and drop tasks between columns
- Persist tasks using mock REST API
- Fully responsive design for mobile and desktop
